# 网文题材模板

## 玄幻修仙

### 核心要素

**境界体系：**
```
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘 → 飞升
（每个境界有九层，如炼气一到九层）
```

**资源类型：**
- 天材地宝：灵草、矿石、妖兽内丹
- 功法秘籍：基础功法、秘术、神通
- 灵器法宝：法器、宝器、道器、仙器
- 修炼资源：灵石、丹药、灵液

**经典设定：**
- 家族势力（血脉传承）
- 宗门体系（师徒传承）
- 国家王朝（世俗权力）
- 远古遗迹（探险机缘）

### 剧情模板

**退婚流：**
```
第一章：天才少年被未婚妻退婚，羞辱
第三章：偶得机缘，开始崛起
第十章：初展实力，打脸嘲讽者
第三十章：未婚妻家族后悔
第一百章：未婚妻求复合
```

**升级流：**
```
获得功法 → 修炼突破 → 获得资源 → 遇到强敌 → 战斗成长 → 获得机缘 → 继续升级
```

**宗门流：**
```
入门测试 → 外门弟子 → 内门弟子 → 真传弟子 → 核心长老 → 宗主
```

### 爽点设计

1. **突破爽点**：境界突破时要有仪式感
2. **战斗爽点**：越级挑战，碾压对手
3. **收获爽点**：获得宝物、法宝、功法
4. **打脸爽点**：打脸曾经看不起自己的人
5. **逆袭爽点**：从绝境中翻盘

## 都市异能

### 核心要素

**异能类型：**
- 超能力系：心灵感应、瞬间移动、预知未来
- 元素系：操控火、水、风、雷、土
- 强化系：身体强化、速度强化、力量强化
- 召唤系：召唤异兽、召唤亡灵、召唤器灵
- 特殊系：时间、空间、因果、命运

**社会结构：**
- 普通社会（表面）
- 异能者社会（里层）
- 异能组织（管理方）
- 地下势力（灰色地带）

### 剧情模板

**总裁流：**
```
误入豪门 → 身份差距 → 感情升温 → 家族反对 → 证明自己 → 圆满结局
```

**兵王流：**
```
退役兵王 → 隐藏身份 → 发现阴谋 → 保护女主 → 解决危机 → 回归平静
```

**神医流：**
```
意外获医书 → 医术惊人 → 治疗大佬 → 得罪权贵 → 绝地反击 → 名利双收
```

### 都市规则

1. **低调原则**：异能不能随意暴露
2. **代价原则**：异能使用有代价或限制
3. **社会规则**：异能也要遵守法律道德
4. **能力守恒**：异能强弱有依据

## 末世求生

### 核心要素

**末世类型：**
- 丧尸爆发：病毒感染，生存危机
- 灾难降临：地震、海啸、火山、陨石
- 辐射变异：核战后物种变异
- 灵气复苏：动植物异变

**生存要素：**
- 物资：水、食物、药品、武器
- 安全：住所、防御、警报
- 团队：同伴、技能、信任
- 信息：地图、情报、安全区

### 剧情模板

**丧尸末世：**
```
爆发初期 → 艰难求生 → 建立基地 → 升级装备 → 清除丧尸 → 建立新秩序
```

**灵气复苏：**
```
灵气初现 → 发现异常 → 获得传承 → 快速升级 → 异兽攻城 → 人类崛起
```

### 末世爽点

1. **收集爽点**：找到大量物资
2. **基地爽点**：建立安全堡垒
3. **异能爽点**：觉醒强大能力
4. **团队爽点**：收获忠诚伙伴
5. **复仇爽点**：清理丧尸群

## 系统流

### 核心要素

**系统类型：**
- 任务系统：完成任务获得奖励
- 升级系统：击杀怪物获得经验
- 抽奖系统：随机获得道具
- 签到系统：每日签到奖励
- 商城系统：用积分购买道具

**系统设定：**
- 系统是金手指，有智能人格
- 系统任务推动剧情
- 系统奖励超出预期
- 系统升级解锁新功能

### 剧情模板

```
获得系统 → 完成新手任务 → 获得首充奖励
快速升级 → 遇到困难任务 → 极限完成任务
解锁功能 → 商城购物 → 实力暴涨
遇到BUG → 触发隐藏任务 → 获得逆天奖励
```

### 系统文技巧

1. **任务设计**：任务要有趣味性和挑战性
2. **奖励设计**：奖励要超出预期
3. **系统互动**：系统要有性格，能吐槽
4. **剧情联动**：系统任务推动主线

## 规则怪谈

### 核心要素

**规则类型：**
- 生存规则：必须遵守否则死亡
- 安全规则：提供安全区域
- 隐藏规则：需要探索发现
- 代价规则：遵守有代价

**世界观：**
- 怪谈世界：独立空间或平行世界
- 怪谈生物：无逻辑但遵守规则
- 逃生条件：满足特定条件
- 玩家身份：参与者或旁观者

### 剧情模板

```
进入怪谈 → 获得初始规则 → 探索世界
发现规则 → 遵守或违反 → 触发后果
遇到NPC → 获得信息 → 继续探索
找到真相 → 完成逃生条件 → 逃离
```

### 怪谈写作技巧

1. **规则要具体**：清晰可执行
2. **氛围要压抑**：营造恐惧感
3. **逻辑要自洽**：规则之间不矛盾
4. **反转要意外**：真相出人意料

## 宫斗宅斗

### 核心要素

**身份体系：**
- 皇帝 → 皇后 → 贵妃 → 妃 → 嫔 → 宫女
- 王爷 → 王妃 → 侧妃 → 侍妾
- 老爷 → 正妻 → 姨娘 → 通房

**斗争手段：**
- 言语机锋：绵里藏针
- 设计陷害：无中生有
- 借刀杀人：利用他人
- 以退为进：示弱反击

### 剧情模板

**宫斗：**
```
选秀入宫 → 低位份 → 被刁难 → 获宠幸
升位份 → 树敌 → 被陷害 → 反击 → 地位稳固
争皇后 → 最终对决 → 成为皇后或隐退
```

**宅斗：**
```
嫁入豪门 → 身份低微 → 被欺压 → 展露手段
站稳脚跟 → 公公宠爱 → 管家权 → 清除异己 → 当家做主
```

### 宫斗技巧

1. **人物要立体**：每个角色有自己的立场
2. **计谋要精妙**：环环相扣
3. **感情要细腻**：爱恨交织
4. **结局要有力**：善恶有报

## 创作提示

### 选择题材考虑因素

1. **个人喜好**：写自己喜欢的
2. **市场趋势**：了解读者口味
3. **创作难度**：评估自己的驾驭能力
4. **更新能力**：能否保持稳定更新

### 题材组合技巧

可以使用"+"组合两个题材：
- 玄幻+系统流
- 都市+异能
- 末世+升级流
- 修仙+穿越

组合时，主辅比例建议 7:3

### 创新方向

1. **设定创新**：独特的世界观
2. **人设创新**：有记忆点的角色
3. **剧情创新**：出人意料的发展
4. **写法创新**：独特的叙事方式
