# 效果验证文档

本文档提供 webnovel-writer 系统各模块的效果验证指南，用于确保系统功能正常工作。

## 验证范围

- 项目初始化模块
- 大纲规划模块
- 章节写作模块
- 质量审查模块
- 设定查询模块
- 批量写作模块
- 可视化面板模块
- 风格学习模块

---

## 一、项目初始化验证

### 验证用例

| 用例ID | 测试场景 | 预期结果 | 验证方法 |
|--------|----------|----------|----------|
| INIT-001 | 创建新项目 | 生成正确的目录结构和配置文件 | 检查 `.webnovel/state.json` 是否存在 |
| INIT-002 | 指定题材初始化 | 题材配置正确写入 state.json | 检查 genre 字段值 |
| INIT-003 | 默认配置初始化 | 使用默认值创建项目 | 检查配置是否为默认值 |

### 验证步骤

1. 执行 `/webnovel-init "书名" --genre 玄幻修仙`
2. 检查目录结构：
   - `正文/` 目录存在
   - `设定/` 目录存在
   - `.webnovel/` 目录存在
3. 检查 `.webnovel/state.json` 内容

### 预期输出示例

```json
{
  "book_name": "逆天改命",
  "genre": "玄幻修仙",
  "target_words": 2000000,
  "target_chapters": 600,
  "current_chapter": 0,
  "total_words": 0
}
```

## 十、整体流程验证

### 完整流程测试

```
1. /webnovel-init "测试小说" --genre 玄幻修仙
   ↓
2. /webnovel-plan generate
   ↓
3. /webnovel-write 1
   ↓
4. /webnovel-review 1
   ↓
5. /webnovel-query character 主角名
   ↓
6. /batch-write 2-5
   ↓
7. /webnovel-dashboard
```

### 验证标准

| 阶段 | 通过标准 |
|------|----------|
| 初始化 | 目录结构完整，配置正确 |
| 规划 | 大纲结构合理，章节规划清晰 |
| 写作 | 章节生成，字数达标，格式正确 |
| 审查 | 审查报告完整，问题可追踪 |
| 查询 | 信息准确，响应及时 |
| 批量 | 队列管理正常，衔接自然 |
| 面板 | 数据展示正确，可视化有效 |

## 注意事项

1. 验证前确保项目目录为空或已正确初始化
2. 所有验证应在测试环境中进行，避免影响正式项目
3. 验证结果应记录到 `.webnovel/validation/` 目录
4. 发现问题应及时反馈并修复
