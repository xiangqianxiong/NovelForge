# `/webnovel-dashboard` - 可视化面板

## 功能说明

启动只读可视化面板，可以浏览项目状态、实体图谱、章节内容和追读力数据。**数据全部从项目目录读取。**

## 项目目录检查（第一步，必须执行）

在启动面板前，按以下顺序确认项目目录：

1. 查找包含 `.webnovel/state.json` 的目录，或目录名明显是书名
2. 找到项目目录后，从该目录读取状态、章节、实体数据
3. 找不到项目目录时，提示"尚未初始化小说项目，请先运行 `/webnovel-init`

**规则：永远从项目目录读取面板数据。找不到项目目录就不启动面板。**

## 面板内容

### 1. 项目概览
- 当前章节进度
- 总字数统计
- 目标完成度
- 近期更新

### 2. 角色图谱
- 核心角色列表
- 角色关系网络
- 角色出场频率

### 3. 章节浏览
- 已完成章节列表
- 章节摘要预览
- 章节审查状态

### 4. 大纲视图
- 卷级大纲
- 章级大纲
- 伏笔追踪

### 5. 追读力分析
- Hook 类型分布
- 爽点密度趋势
- 读者期待度

## 使用方式

1. 系统启动本地 Web 服务器
2. 打开浏览器访问面板
3. 面板为只读模式，不修改项目文件

## 技术实现

面板包含：
- 前端可视化界面（HTML/CSS/JS）
- 本地数据服务
- 文件监听（可选刷新）

## 注意事项

- 面板为**只读**，不会修改项目文件
- 仅读取 `.webnovel/` 和项目目录
- 支持实时刷新（如启用文件监听）
