# `/webnovel-dashboard` - 可视化面板

## 功能说明

启动可视化面板，以只读方式展示小说项目的完整状态，包括进度、实体关系、章节内容和追读力分析。

## 什么时候使用这个技能

- 用户想要查看项目的整体进度和统计
- 用户想要了解角色关系和出场情况
- 用户想要浏览已写章节和大纲
- 用户想要分析追读力和爽点分布
- 用户提到"可视化面板"、"仪表盘"、"dashboard"等关键词

## Phase 1: 准备与初始化

### Step 1: 验证项目状态
1. **检查是否为有效的 webnovel 项目**
   - 确认当前目录是否包含 `.webnovel/state.json`
   - 如果没有，提示用户"先在小说项目目录中运行此命令"

2. **读取项目数据**
   - 读取 `.webnovel/state.json`
   - 读取章节列表和摘要
   - 读取设定文件和大纲

### Step 2: 构建可视化内容

## Phase 2: 展示面板内容

### 1️⃣ 项目概览
- 当前章节进度
- 总字数统计
- 目标完成度 (当前字数 / 目标字数)
- 近期更新记录
- 状态标签 (进行中/暂停/已完成)

### 2️⃣ 角色图谱
- 核心角色列表
- 角色关系网络图
- 角色出场频率统计
- 角色成长轨迹

### 3️⃣ 章节浏览
- 已完成章节列表（按卷/章组织）
- 章节摘要预览
- 章节审查状态
- 爽点标记
- 钩子标记

### 4️⃣ 大纲视图
- 卷级大纲展示
- 章级大纲展示
- 伏笔追踪（活跃/已回收）
- Strand 节奏分布

### 5️⃣ 追读力分析
- Hook 类型分布
- 爽点密度趋势图
- 读者期待度曲线
- 章末钩子强度评分

## Phase 3: 交互说明

### 使用方式
1. 系统启动本地 Web 服务器（如果可用）
2. 展示 Markdown 格式的结构化可视化面板（备用方案）
3. 面板为**只读模式**，不修改任何项目文件

### 输出格式
优先输出 Markdown 格式的面板，包含：
- 清晰的标题层级
- 表格展示统计数据
- 列表展示章节和角色
- 分隔线区分不同模块

## 边界条件处理

### 异常场景处理

| 场景 | 触发条件 | 处理动作 |
|------|----------|----------|
| 项目未初始化 | 找不到 `.webnovel/state.json` | 提示用户"请先使用 `/webnovel-init` 初始化项目" |
| 无章节数据 | 项目已初始化但无正文 | 显示"尚未写作任何章节"，提供大纲预览 |
| 数据损坏 | 状态文件读取失败 | 提示用户检查文件，提供从备份恢复的建议 |
| 部分数据缺失 | 缺少某些设定文件 | 跳过缺失部分，展示可用数据 |

## 检查点设计

### 用户确认（如需要）
| 检查点 | 触发时机 | 确认内容 |
|--------|----------|----------|
| 展示敏感数据 | 如果项目包含敏感设定 | 确认是否展示完整设定信息 |

## 技术实现说明

### 面板类型
- **类型 A（Web面板）**：启动本地 Web 服务器（可选）
- **类型 B（Markdown面板）**：默认输出 Markdown 格式的可视化内容

### 技术要点
- 前端可视化界面（HTML/CSS/JS，可选）
- 本地数据服务（读取 JSON 文件）
- 文件监听（可选实时刷新）
- **默认采用 Markdown 面板**，确保兼容性

## 注意事项

- 面板为**只读**，不会修改任何项目文件
- 仅读取 `.webnovel/`、`设定集/`、`大纲/`、`正文/` 目录
- 支持实时刷新（如果启用文件监听）
- 使用中文展示所有内容
