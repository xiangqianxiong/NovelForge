# `/webnovel-learn` - 写作模式学习

## 功能说明

从当前会话或用户输入中，智能识别并提取可复用的写作模式、技巧和风格偏好，结构化地保存到项目长期记忆中，供后续写作参考使用。

## 什么时候使用这个技能

- 用户总结本次写作经验时
- 用户发现有效的写作技巧并想要记录时
- 用户需要固化自己的写作风格模式时
- 用户提到"学习模式"、"记录经验"、"技巧总结"等关键词时

## Phase 1: 解析输入

### Step 1: 验证项目状态
1. **检查项目状态**
   - 确认当前目录是否为有效的 webnovel 项目
   - 如果没有，提示用户"请先使用 `/webnovel-init` 初始化项目"

### Step 2: 理解用户输入
1. **解析用户提供的内容**
   - 分析用户输入的文本
   - 识别用户想要学习的写作模式类型
   - 询问用户补充（如需要）

## Phase 2: 提取模式

### 学习内容类型

#### 1️⃣ 钩子设计
```json
{
  "type": "hook_pattern",
  "pattern": "悬念钩",
  "description": "用未解之谜吸引读者",
  "example": "他究竟是谁？",
  "source_chapter": 1
}
```

#### 2️⃣ 爽点设计
```json
{
  "type": "cool_point",
  "pattern": "装逼打脸",
  "description": "主角在嘲讽者面前展现实力",
  "conditions": ["被嘲讽", "隐藏实力", "强势反击"],
  "source_chapter": 1
}
```

#### 3️⃣ 节奏模式
```json
{
  "type": "pacing_pattern",
  "pattern": "压抑-爆发",
  "description": "先压抑情绪，再一次性释放",
  "example": "主角一直被压制，章末逆袭",
  "source_chapter": 1
}
```

#### 4️⃣ 对话技巧
```json
{
  "type": "dialogue_pattern",
  "pattern": "潜台词对话",
  "description": "对话表面一层意思，底下藏另一层",
  "example": "问东答西，欲言又止",
  "source_chapter": 1
}
```

#### 5️⃣ 打斗描写
```json
{
  "type": "combat_description",
  "pattern": "简洁战斗描写",
  "description": "用简短的动作描写表现战斗",
  "example": "萧炎抬手，一拳轰出。",
  "source_chapter": 1
}
```

## Phase 3: 保存与反馈

### Step 1: 保存到记忆
1. **读取现有 project_memory.json**
   - 如果文件不存在，初始化一个新的

2. **追加新模式**
   - 根据类型放入对应的数组
   - 自动记录时间戳和来源章节

3. **保存文件**
   - 写入 `.webnovel/project_memory.json`

### Step 2: 给用户反馈
- 显示已学习的模式信息
- 显示当前记忆中的模式数量

## project_memory.json 结构

```json
{
  "hook_patterns": [],
  "cool_points": [],
  "pacing_patterns": [],
  "dialogue_patterns": [],
  "combat_patterns": [],
  "other_patterns": [],
  "updated_at": "2026-05-22T00:00:00Z"
}
```

## 边界条件处理

### 异常场景处理

| 场景 | 触发条件 | 处理动作 |
|------|----------|----------|
| 项目未初始化 | 找不到 `.webnovel/state.json` | 提示用户"请先使用 `/webnovel-init` 初始化项目" |
| 输入不明确 | 用户输入太模糊 | 询问用户更具体的信息，提供示例 |
| 类型无法识别 | 无法确定模式类型 | 归类为 `other_patterns`，请用户确认 |
| 文件写入失败 | 无法保存 JSON | 提示用户检查权限，展示内容让用户手动保存 |

## 检查点设计

### 用户确认（如需要）
| 检查点 | 触发时机 | 确认内容 |
|--------|----------|----------|
| 保存模式 | 在追加到记忆之前 | 展示提取的模式，请用户确认是否正确 |

## 完整示例

用户输入：`/webnovel-learn "这章的打斗设计很紧凑，一招一式都有画面感"`

系统执行：
1. 解析输入 → 识别为「打斗描写」
2. 提取模式 → 生成结构化记录
3. 保存到 `.webnovel/project_memory.json`
4. 反馈给用户 → "已学习模式：简洁战斗描写"

## 注意事项

- 始终使用中文
- 尽量提取具体、可复用的模式
- 保存时不要覆盖已有内容，只追加
- 模式来源章节记录可选，如有则记录
