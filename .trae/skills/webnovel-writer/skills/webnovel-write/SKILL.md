# `/webnovel-write` - 写作章节

## 功能说明

执行完整的章节写作流程，包括写前准备、草稿写作、质量审查和润色修改。

## 参数

- `[章号]`：要写作的章节号，如 `1`、`45`

## 完整流程

### 1. 写前准备（Context Agent）

调用 context-agent：
1. 读取章级大纲
2. 查询角色状态
3. 查询伏笔追踪
4. 生成五段式写作任务书

**写作任务书格式**：
1. 开篇委托：书名、章号、标题、一句话目标
2. 这章的故事：前文摘要、本章目标/阻力、情节节点
3. 这章的人物：状态、驱动力、本章作用
4. 怎么写更顺：风格指导、Anti-AI 提醒
5. 收在哪里：结尾感觉、未完感

### 2. 起草正文

按照任务书写作，遵循：
- **防幻觉三定律**
- **Strand 节奏控制**
- **章节字数要求**（玄幻3000-4000字/章）

### 3. 质量审查（Reviewer）

调用 reviewer 执行六维审查：
- High-point：爽点密度
- Consistency：设定一致性
- Pacing：节奏比例
- OOC：角色一致性
- Continuity：叙事连贯性
- Reader-pull：钩子强度

### 4. 润色修改

根据审查意见修改，不接受"这里应该..."的建议，只修复可验证的问题。

### 5. 数据更新（Data Agent）

1. 提取实体和状态变更
2. 生成章节摘要
3. 更新伏笔追踪
4. 更新 strand_tracker

## 防幻觉三定律

1. **大纲即法律**：遵循大纲，不擅自发挥
2. **设定即物理**：遵守设定（能力≤已有记录）
3. **发明需识别**：新实体由 data-agent 提取

## Anti-AI 对抗

- 删除段末感悟句，留余味
- 删除万能副词（缓缓/淡淡/微微）
- 情绪用生理反应+微动作
- 对话带潜台词
- 制造节奏疏密对比
- 章末禁止安全着陆

## 输出

保存到 `正文/第{章号}章-{标题}.md`

同时更新：
- `.webnovel/state.json`
- `.webnovel/summaries/第{章号}章.md`
- `大纲/伏笔追踪.md`（如有新伏笔）
