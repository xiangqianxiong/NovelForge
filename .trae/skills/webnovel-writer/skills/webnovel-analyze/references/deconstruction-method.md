# 拆解方法论

## 核心原则

### 1. 从读者视角拆解
不要从"作者想表达什么"角度拆解，而要从"读者感受到什么"角度拆解。

### 2. 结构化提取
将感性的阅读体验转化为可量化的结构数据。

### 3. 技巧归类
将拆解出的技巧归入标准分类，方便后续学习应用。

## 拆解层级

### 宏观层面

1. **题材定位**
   - 类型判断
   - 目标平台
   - 读者画像

2. **故事框架**
   - 主线类型
   - 核心冲突
   - 驱动力来源

3. **结构模式**
   - 起承转合
   - 高潮分布
   - 转折节点

### 中观层面

1. **人设架构**
   - 主角设定
   - 配角功能
   - 关系网络

2. **爽点设计**
   - 爽点类型
   - 爽点密度
   - 铺垫技巧

3. **节奏控制**
   - 章节节奏
   - 卷级节奏
   - 全书节奏

### 微观层面

1. **开篇技巧**
   - 首句设计
   - 钩子铺设
   - 信息密度

2. **对话技巧**
   - 标签词使用
   - 潜台词设计
   - 对话节奏

3. **情绪技巧**
   - 心理vs动作
   - 生理反应替代
   - 情绪词汇选择

4. **场景技巧**
   - 场景切换
   - 视角控制
   - 细节描写

## 黄金三章拆解指南

### 第一章拆解重点

**开篇三要素：**
1. 立即进入冲突/悬念
2. 快速建立主角认知
3. 给出追读理由

**拆解问题清单：**
- 第一句话/段在做什么？
- 主角是谁？读者如何认识的？
- 核心矛盾/悬念是什么？
- 为什么不放下？

**常见开篇模式：**

| 模式 | 特征 | 适用题材 |
|------|------|----------|
| 冲突开场 | 直接进入危机 | 都市、玄幻 |
| 日常开场 | 先建立认知再冲突 | 言情、生活 |
| 倒叙开场 | 先展示结果再回溯 | 悬疑、复仇 |
| 穿越开场 | 异世界直接开始 | 系统、玄幻 |

### 第二章拆解重点

**核心任务：**
1. 建立世界观/规则
2. 展示主角能力/金手指
3. 埋设第一个伏笔

**拆解问题清单：**
- 世界观如何自然引入？
- 金手指展示方式？
- 第一个钩子/伏笔？

### 第三章拆解重点

**核心任务：**
1. 第一个小高潮
2. 强化读者期待
3. 建立追读惯性

**拆解问题清单：**
- 第一个高潮是什么？
- 高潮后留下了什么悬念？
- 读者接下来想看什么？

## 角色拆解指南

### 主角拆解

**核心要素：**
1. 身份背景
2. 核心性格
3. 能力/金手指
4. 动机/目标
5. 缺陷/弱点

**拆解问题清单：**
- 主角最吸引人的特质是什么？
- 主角的成长路径是什么？
- 主角与读者的共鸣点在哪里？

### 配角拆解

**配角分类：**

| 类型 | 功能 | 拆解重点 |
|------|------|----------|
| 助攻型 | 帮助主角 | 如何帮助、动机 |
| 对立型 | 制造冲突 | 冲突来源、威胁程度 |
| 功能型 | 推动剧情 | 何时出场、功能 |
| 情感型 | 增加趣味 | 与主角的关系 |

### 关系网络

**关系提取维度：**
1. 身份关系（亲人、师徒、敌友）
2. 情感关系（爱恨、亲疏）
3. 利益关系（合作、对立）
4. 演变关系（初始→发展→结果）

## 剧情拆解指南

### 主线识别

**常见主线类型：**

| 类型 | 特征 | 驱动核心 |
|------|------|----------|
| 升级流 | 实力提升 | 变强欲望 |
| 复仇流 | 恩怨纠葛 | 报仇雪恨 |
| 感情流 | 情感发展 | 爱恨情仇 |
| 悬疑流 | 谜题解开 | 真相追求 |
| 冒险流 | 探索未知 | 好奇心 |

### 爽点拆解

**爽点类型库：**

| 类型 | 子类 | 触发场景 |
|------|------|----------|
| 打脸爽 | 正打脸、反打脸 | 碾压、嘲讽 |
| 升级爽 | 突破、获得技能 | 战斗、任务 |
| 收获爽 | 获得物品/美人 | 奖励、奇遇 |
| 装逼爽 | 被认可、隐藏实力曝光 | 众人面前展示 |
| 反转爽 | 绝地翻盘、意外收获 | 危机时刻 |
| 情感爽 | 表白成功、甜蜜互动 | 感情戏 |
| 解谜爽 | 真相揭示 | 悬疑戏 |

**爽点密度分析：**
- 优秀作品：每3-5章一个中高潮
- 顶级作品：每章都有小爽点
- 节奏红线：任何类型超过10章无爽点

### 伏笔拆解

**伏笔类型：**

| 类型 | 特征 | 回收时机 |
|------|------|----------|
| 人物伏笔 | 身份、命运 | 中后期 |
| 物品伏笔 | 道具、秘籍 | 需要时 |
| 情节伏笔 | 事件、冲突 | 1-3章后 |
| 世界观伏笔 | 规则、秘密 | 关键节点 |

**伏笔分布：**
- 开篇：1-2个轻伏笔
- 前期：埋设中伏笔
- 中期：埋设重大伏笔
- 后期：密集回收

## 节奏拆解指南

### 章节节奏

**单章节奏模式：**

```
铺垫（20%）→ 积累（30%）→ 高潮（30%）→ 钩子（20%）
```

**节奏类型：**

| 类型 | 适用场景 | 节奏特点 |
|------|----------|----------|
| 递进式 | 升级、打脸 | 层层加码 |
| 波浪式 | 感情、日常 | 起伏交替 |
| 悬念式 | 悬疑、揭秘 | 持续紧张 |
| 并行式 | 多线叙事 | 交替推进 |

### 卷级节奏

**常见结构：**

```
起（建立，20%）→ 承（发展，30%）→ 转（危机，30%）→ 合（高潮，20%）
```

### 全书节奏

**大高潮分布：**
- 每50-100章一个大型高潮
- 每个大高潮前有2-3个中高潮铺垫
- 大高潮后需要1-2章的收束和铺垫

## 文风拆解指南

### 句式分析

**统计维度：**
- 平均句长
- 短句比例（1-10字）
- 长句比例（20字以上）
- 句式变化度

**句式风格库：**

| 风格 | 特征 | 代表场景 |
|------|------|----------|
| 简洁干脆 | 短句为主 | 打斗、冲突 |
| 细腻绵长 | 长句描写 | 感情、心理 |
| 跳跃剪辑 | 短句切换 | 紧张、悬疑 |
| 对话为主 | 大量对话 | 谈判、冲突 |

### 对话分析

**标签词统计：**
- 高频标签词（"说"/"道"/"问"）
- 无标签对话比例
- 动作标签使用

**对话功能分类：**

| 功能 | 特征 | 作用 |
|------|------|------|
| 推进型 | 直接推进剧情 | 交代信息 |
| 展示型 | 展示人物性格 | 塑造形象 |
| 潜台词型 | 言外之意 | 增加深度 |
| 冲突型 | 对立观点 | 制造张力 |

### 情绪表达分析

**替代关系：**

| 直接心理描写 | 动作/生理替代 |
|--------------|---------------|
| 他很紧张 | 手在抖、握紧拳头 |
| 她很悲伤 | 眼眶红了、转身离开 |
| 他很愤怒 | 一拳砸在桌上 |
| 她很惊讶 | 愣在原地 |

### 特色技巧记录

**常见技巧库：**

1. **一笔两用**：一个描写同时完成多个功能
2. **延迟揭示**：信息分批透露
3. **视角欺骗**：故意误导读者视角
4. **对比锚点**：通过对比突出重点
5. **意象贯穿**：核心意象在不同场景重复
6. **身体反应**：用生理反应替代心理描写
7. **跨章回扣**：物品/意象在不同章节承担不同功能
