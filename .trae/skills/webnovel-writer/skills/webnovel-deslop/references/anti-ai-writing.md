# 系统性去AI三遍法

## 核心思想

去AI味的本质是把文字从「过度工整」拉回「具体、自然、可读」。

AI写作的特点：
- 过于圆滑（没有棱角）
- 过于工整（句式整齐）
- 过于充分（生怕读者不懂）
- 过于正确（没有意外）

## 三遍法概述

### Pass 1：去泛化
处理AI味的第一个来源：**泛化的表达**

### Pass 2：去书面化
处理AI味的第二个来源：**过度书面的表达**

### Pass 3：回自然感
处理AI味的第三个来源：**缺少具体和意外**

---

## Pass 1：去泛化

### 目标
删除所有让文字变得模糊、泛化、万能的表达。

### 检查清单

#### 1. 删除万能副词

| 原词 | 处理方式 |
|------|----------|
| 缓缓 | 删除或换成具体速度 |
| 淡淡 | 删除或换成具体程度 |
| 微微 | 删除或换成具体程度 |
| 轻轻 | 删除或换成具体力度 |
| 渐渐 | 删除或换成具体过程 |
| 慢慢 | 删除或换成具体描述 |

**示例：**
- ❌ "他缓缓睁开眼睛"
- ✅ "他睁开眼"

- ❌ "她淡淡一笑"
- ✅ "她笑了一下"

#### 2. 删除万能形容词

| 原词 | 处理方式 |
|------|----------|
| 不可思议 | 换成具体感受 |
| 难以置信 | 换成具体反应 |
| 无与伦比 | 换成具体描述 |
| 震撼人心 | 换成具体效果 |

**示例：**
- ❌ "他的实力不可思议"
- ✅ "他的剑快得看不清"

#### 3. 删除万能比喻

| 原词 | 处理方式 |
|------|----------|
| 如寒冰般 | 删除或换成生活化比喻 |
| 如星辰般 | 删除或具体化 |
| 如潮水般 | 删除或具体化 |

**示例：**
- ❌ "她的目光如寒冰般"
- ✅ "她的目光刺过来"

#### 4. 替换"仿佛/如同/犹如"

**规则：** 这类词90%可以删除或换成"像"。

**示例：**
- ❌ "他仿佛知道什么"
- ✅ "他应该知道些什么"

- ❌ "天空如同染血"
- ✅ "天空像被血染红"

---

## Pass 2：去书面化

### 目标
将过于书面化的表达转为口语化、自然的表达。

### 检查清单

#### 1. 简化对话标签

| 禁用 | 替代 |
|------|------|
| 说道 | 说 |
| 问道 | 问 |
| 笑道 | 笑 |
| 叹气道 | 叹气 |
| 喃喃道 | 低声说 |
| 缓缓道 | 直接说 |

**规则：** 60%以上的对话不需要标签。

#### 2. 删除书面语气词

| 禁用 | 替代 |
|------|------|
| ...地 | 直接接动词/形容词 |
| ...的样子 | 删除 |
| ...的神情 | 换成具体动作 |

**示例：**
- ❌ "他慢慢地站起身来"
- ✅ "他站起来"

- ❌ "他露出受伤的样子"
- ✅ "他的脸色变了"

#### 3. 替换书面判断词

| 禁用 | 替代 |
|------|------|
| 他知道 | 他明白/他想着/直接不说 |
| 他明白 | 直接呈现思考 |
| 不容置疑 | 具体事实说话 |
| 显而易见 | 具体事实说话 |

**示例：**
- ❌ "他知道自己错了"
- ✅ "他不说话"

- ❌ "他明白她的意思"
- ✅ "他点头"

#### 4. 打断万能状语结构

**识别模式：** "...，带着..."

**处理：** 把状语变成独立句子或动作。

**示例：**
- ❌ "他抬起头，带着自信的笑容"
- ✅ "他抬起头。笑得很自信。"

---

## Pass 3：回自然感

### 目标
增加具体性、口语感、节奏变化。

### 检查清单

#### 1. 增加具体动作

**规则：** 用身体部位的具体动作替代抽象情绪。

| 原表达 | 替代动作 |
|--------|----------|
| 他很紧张 | 手在抖/额头冒汗 |
| 她很愤怒 | 一把掀翻桌子/握紧拳头 |
| 他很害怕 | 腿在发软/往后退 |
| 她很悲伤 | 眼眶红了/转身离开 |

**示例：**
- ❌ "他心里很紧张"
- ✅ "他的手在抖"

#### 2. 增加潜台词

**规则：** 对话不只是字面意思，有言外之意。

**示例：**
- ❌ "你说得对，我们合作吧"
- ✅ "你说得对。"他顿了顿，"行，合作。"

#### 3. 增加口语化

**规则：** 加入语气词、口语表达。

**可用词：**
- "嗯""哦""啊""行吧""算了""靠""嘶"

**示例：**
- ❌ "我知道了"
- ✅ "哦，知道了"

#### 4. 增加节奏对比

**规则：** 不要每段都一样的长度和节奏。

**技巧：**
- 一个超短句 + 一个长句
- 三个短句突然一个长句
- 对话和叙述交替

**示例：**
```
他站起来。
走到窗边，看着外面的夜色。很久了。
"我该走了。"
```

#### 5. 适当留白

**规则：** 不需要解释一切，让读者自己脑补。

**删除：** 感悟句、总结句、解释句

**示例：**
- ❌ "他明白了，原来她一直在等他。"
- ✅ "他沉默了很久。"

#### 6. 对话被打断

**规则：** 真实对话经常被打断。

**示例：**
- ❌ "我——" "别说了。"
- ✅ "我——"他刚开口。

## 实战范例

### 原文（AI味重）

```
张伟深吸一口气，眼中闪过一丝不易察觉的悲伤。

"我知道，"他缓缓开口，声音带着一丝颤抖，
"这一切都是命中注定的。"

他缓缓站起身，嘴角勾起一抹苦涩的笑容。
他明白，从这一刻起，一切都将改变。
```

### 三遍改后

```
张伟不说话了。

"我知道。"他开口，又停下。"算了，不说了。"

他站起来。走到窗边。
"走了。"

他的手在抖。
```

### 改动说明

| 原句 | 改动 | 理由 |
|------|------|------|
| 深吸一口气 | 删除 | 90%无意义 |
| 眼中闪过一丝悲伤 | 手在抖 | 动作展示情绪 |
| 缓缓开口 | 删除 | 书面腔 |
| 带着一丝颤抖 | 删除 | 泛化描写 |
| 命中注定 | 删除 | 升华腔 |
| 嘴角勾起一抹苦涩的笑 | 笑了一下 | 具体+简洁 |
| 他明白 | 删除 | 直接呈现 |
| 从这一刻起，一切都将改变 | 删除 | 总结升华 |

## 常见问题

### Q1：删太多了怎么办？

**A：** 如果修改比例超过阈值（轻度15%/中度25%/重度35%），标记超限风险。

### Q2：删了之后节奏变薄了怎么办？

**A：** 不要删除，而是「降AI重写」——保持内容，但改变表达方式。

### Q3：不确定的内容怎么办？

**A：** 标注 `[需复核]`，不要强行修改。

### Q4：人名/地名/术语也要改吗？

**A：** 不改。这些优先保留。
