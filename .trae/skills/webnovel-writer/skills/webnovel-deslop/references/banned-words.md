## 统计指标

### 禁用词密度计算

```
禁用词密度 = 命中次数 / 总字数 * 1000
```

| 密度区间 | AI味程度 |
|----------|----------|
| ≤5 处/千字 | 轻度 |
| 6-15 处/千字 | 中度 |
| >15 处/千字 | 重度 |

## 白名单机制

项目根目录下的 `.deslop-whitelist` 文件定义豁免词汇：

```
# 示例白名单
深吸一口气    # 特定角色口头禅
缓缓          # 特定角色说话方式
```

匹配规则：精确匹配（非子串），一行一个。

适用场景：
- 术语（如玄幻术语）
- 角色口头禅
- 世界观专有名词
- 原文刻意使用的修辞
