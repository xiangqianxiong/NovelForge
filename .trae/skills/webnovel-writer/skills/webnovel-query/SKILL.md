# `/webnovel-query` - 查询系统

## 功能说明

查询项目运行时状态，包括角色、伏笔、剧情、节奏等信息。

## 参数

- `[关键词]`：查询内容，如 `萧炎`、`伏笔`、`剧情`、`节奏`

## 查询类型

### 角色查询
```
/webnovel-query 萧炎
```
输出：
- 角色基本信息
- 当前境界/状态
- 近期出场章节
- 关系网络

### 伏笔追踪
```
/webnovel-query 伏笔
```
输出：
- 所有活跃伏笔列表
- 埋设章节和预期回收章节
- 超期未回收伏笔
- 紧急伏笔（remaining ≤ 5）

### 剧情状态
```
/webnovel-query 剧情
```
输出：
- 主线进度
- 近期重大事件
- 下章预期发展

### 节奏分析
```
/webnovel-query 节奏
```
输出：
- Strand 分布统计
- Quest/Fire/Constellation 比例
- 断档警告
- 节奏红线检测

## 数据来源

查询以下文件：
- `.webnovel/state.json`
- `.webnovel/summaries/*.md`
- `设定集/主角卡.md`
- `大纲/伏笔追踪.md`
