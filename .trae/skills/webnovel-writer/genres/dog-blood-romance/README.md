# 狗血言情题材详细配置

## 核心要素

### 情感纠葛
- 多角恋（三角、四角、N角）
- 误会与错过
- 身份差距
- 家族反对

### 经典桥段
- 替身梗：白月光的替身
- 误会梗：听到一半就下结论
- 失忆梗：忘了最爱的人
- 绝症梗：韩剧三宝之一
- 复仇梗：为了复仇接近仇人之子

### 情绪节奏
```
虐→甜→虐→甜→虐→大团圆
```

## 套路模板

### 替身文
```
开局：女主长得像白月光
发展：男主把女主当替身→日久生情→白月光回归
冲突：男主选择谁？女主发现真相
高潮：揭穿替身真相
结局：真爱战胜替身
```

### 豪门总裁
```
开局：灰姑娘误入豪门
发展：被误解→被追求→被陷害
冲突：身份差距→家族反对→商战阴谋
高潮：破产/危机/揭穿
结局：霸道总裁爱上我
```

### 先虐后甜
```
开局：甜蜜恋爱
转折：误会/陷害/家族干预
虐心：分离/误解/痛苦
转机：真相大白/重逢
甜蜜：大团圆
```

## 爽点设计

| 类型 | 描述 |
|------|------|
| 心动瞬间 | 第一次心动的小细节 |
| 暧昧拉扯 | 欲拒还迎的情感博弈 |
| 吃醋梗 | 无理由占有欲 |
| 壁咚/车咚 | 肢体接触制造心跳 |
| 英雄救美 | 关键时刻的挺身而出 |

## 写作要点

### 对话设计
- 嘴硬心软的反差
- 口是心非的表达
- 话里有话的潜台词

### 情绪渲染
- 心理描写要细腻
- 眼泪、颤抖等生理反应
- 环境烘托情绪

### 节奏把控
- 虐的时候要彻底
- 甜的时候要到位
- 转折要有爆发力
