# 玄幻题材详细配置

## 核心要素

### 境界体系
```
炼气（九层）→ 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘 → 飞升
```

### 资源类型
- **天材地宝**：灵草、矿石、妖兽内丹
- **功法秘籍**：基础功法、秘术、神通
- **灵器法宝**：法器、宝器、道器、仙器
- **修炼资源**：灵石、丹药、灵液

### 势力体系
- 宗门（传承有序）
- 家族（血脉传承）
- 王朝（世俗权力）
- 散修（游走灰色）
- 妖族（深山野林）

## 经典套路

### 退婚流
```
开局：天才被未婚妻退婚，羞辱
发展：羞辱→逆袭→打脸
爽点：退婚一时爽，追妻火葬场
```

### 升级流
```
获得功法 → 修炼突破 → 获得资源 → 遇到强敌 → 战斗成长 → 获得机缘 → 继续升级
```

### 宗门流
```
入门测试 → 外门弟子 → 内门弟子 → 真传弟子 → 核心长老 → 宗主
```

## 爽点设计

| 类型 | 描述 | 频率 |
|------|------|------|
| 突破爽点 | 境界突破时的仪式感 | 每10-15章 |
| 战斗爽点 | 越级挑战，碾压对手 | 每3-5章 |
| 收获爽点 | 获得宝物、法宝、功法 | 每5-8章 |
| 打脸爽点 | 打脸曾经看不起自己的人 | 每3-5章 |
| 逆袭爽点 | 从绝境中翻盘 | 每10-15章 |

## 写作要点

### 境界描写
- 每个境界有独特特征
- 突破需要契机和代价
- 战力差距要有明显体现

### 战斗描写
- 功法特色要鲜明
- 战斗节奏要紧凑
- 胜负要有合理依据

### 资源争夺
- 天材地宝要有稀缺性
- 争夺要有理由和代价
- 获得者要有成长空间
