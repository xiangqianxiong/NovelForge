# 无限流题材配置

## 题材概述

无限流以主神空间为载体，主角进入各种副本世界完成任务，融合多种题材元素。

## 核心要素

### 世界观设定

#### 主神空间

- 主神：至高存在
- 空间规则：生死搏杀、任务限制
- 强化体系：血统、技能、装备
- 货币系统：积分、点券

#### 副本类型

- 恐怖片世界
- 电影世界
- 游戏世界
- 小说世界
- 原创世界

### 核心设定

- 任务限制：时间、人数、难度
- 死亡惩罚：真实死亡
- 团队配合：分工协作
- 隐藏剧情：额外奖励

## 人物设定

### 主角类型

- 老玩家：经验丰富
- 新人：菜鸟成长
- 强化者：专精某系
- 指挥者：领导型

### 女主类型

- 队友型
- 竞争对手
- NPC/剧情人物
- 其他空间来客

## 写作要点

### 开篇钩子

- 被选中进入空间
- 首个副本世界
- 团队组建
- 强化选择

### 爽点设计

- 副本通关
- 隐藏剧情
- 稀有掉落
- 实力提升
- 团队配合

### 节奏控制

- Quest 60%：副本任务
- Fire 15%：感情羁绊
- Constellation 25%：空间秘密、主神真相

## 参考元素

### 副本世界

- 恐怖片：僵尸、厉鬼、异形
- 动作片：武侠、枪战、格斗
- 科幻片：星际、机甲、赛博
- 魔幻片：魔法、异界、神话

### 强化体系

- 血统强化：吸血鬼、狼人、精灵
- 技能强化：武功、法术、科技
- 装备强化：武器、防具、道具
- 特殊强化：规则、概念、因果

## 防雷指南

- 避免副本过于简单
- 避免强化过于万能
- 避免无限世界设定矛盾
- 避免死亡惩罚不够
