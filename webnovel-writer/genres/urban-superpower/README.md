# 都市异能题材配置

## 题材概述

都市异能是现代都市背景与超能力元素结合的题材，讲述普通人在都市中获得异能后的冒险与成长。

## 核心要素

### 世界观设定

- **现代都市背景**：以现实城市为原型，加入异能元素
- **异能体系**：超能力觉醒、修炼体系
- **势力格局**：官方组织、民间势力、异能者联盟

### 人物设定

#### 主角类型

- 普通人意外觉醒异能
- 异能世家子弟
- 退役异能战士
- 异能研究者

#### 女主类型

- 同伴/战友型
- 竞争对手型
- 神秘组织成员
- 异能世家小姐

### 核心冲突

- 个人成长：异能觉醒、控制、进阶
- 势力斗争：组织对抗、资源争夺
- 社会矛盾：异能者与普通人的关系
- 隐藏阴谋：幕后黑手、远古秘密

## 写作要点

### 开篇钩子

- 异能觉醒事件
- 神秘组织接触
- 都市异常事件
- 身份危机

### 爽点设计

- 异能首次使用
- 以弱胜强战斗
- 身份打脸
- 能力进阶突破
- 势力扩张

### 节奏控制

- Quest 60%：异能成长、任务完成
- Fire 25%：感情发展
- Constellation 15%：世界观展开

## 参考元素

### 异能类型

- 元素系：火、水、风、雷、土
- 精神系：读心、控心、幻术
- 身体强化：力量、速度、防御
- 特殊系：时间、空间、因果

### 场景设定

- 现代都市标志性建筑
- 异能者聚集地
- 神秘组织基地
- 都市传说地点

## 防雷指南

- 避免异能过于万能
- 避免主角开挂过于明显
- 避免都市背景不真实
- 避免异能设定自相矛盾
