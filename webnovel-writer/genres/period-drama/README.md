# 年代文题材详细配置

## 核心要素

### 时代背景
- 改革开放（70-90年代）
- 特殊历史时期
- 地域特色（东北、川渝、广粤等）

### 社会变迁
- 物质匮乏到丰富
- 观念碰撞与转变
- 机遇与挑战并存

## 套路模板

### 年代经营
```
穿越到过去 → 发现商机
从小生意做起 → 积累资本
遭遇困难 → 智慧解决
事业有成 → 收获爱情
时代变迁 → 见证历史
```

### 年代知青
```
下乡插队 → 艰苦生活
遇到真爱 → 身份差距
回城风波 → 分离与等待
改革春风 → 创业奋斗
大团圆结局 → 功成名就
```

## 爽点设计

| 类型 | 描述 |
|------|------|
| 信息差爽点 | 用未来知识降维打击 |
| 打脸爽点 | 让小人后悔 |
| 逆袭爽点 | 从底层爬上来 |
| 感情爽点 | 细水长流的爱情 |

## 写作要点

### 时代细节
- 物价、货币、票证
- 流行歌曲、影视
- 社会风俗、人情往来

### 地域特色
- 方言运用
- 饮食文化
- 气候环境

### 人物塑造
- 鲜明的时代标签
- 朴素真挚的情感
- 坚韧不拔的性格
