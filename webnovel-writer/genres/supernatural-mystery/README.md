# 悬疑灵异题材配置

## 题材概述

悬疑灵异以灵异事件、神秘现象为背景，融合恐怖、推理、探险元素，营造紧张刺激的氛围。

## 核心要素

### 灵异类型

#### 恐怖悬疑

- 厉鬼索命
- 邪教祭祀
- 古老诅咒
- 灵异空间

#### 盗墓探险

- 古墓探秘
- 宝藏传说
- 机关阵法
- 神秘遗迹

#### 推理破案

- 离奇死亡
- 超自然犯罪
- 隐藏真相
- 心理博弈

### 世界观设定

#### 灵异体系

- 鬼魂存在：怨灵、厉鬼、善鬼
- 修炼体系：茅山术、赶尸术、降头术
- 灵异组织：捉鬼师、驱魔人
- 灵异物品：法器、古董、邪物

#### 力量设定

- 阴阳眼
- 道术符咒
- 法器宝物
- 特殊体质

## 人物设定

### 主角类型

- 茅山传人
- 天师后裔
- 普通人觉醒
- 驱魔组织成员

### 女主类型

- 女鬼/狐妖
- 同伴驱魔师
- 灵异体质者
- 神秘组织成员

## 写作要点

### 开篇钩子

- 灵异事件发生
- 神秘人物接触
- 家族秘密揭露
- 诅咒降临

### 爽点设计

- 破解机关
- 击败厉鬼
- 揭露真相
- 获得法器
- 收服灵宠

### 节奏控制

- Quest 45%：探险、解谜、战斗
- Fire 15%：感情线
- Constellation 40%：世界观、灵异知识

## 参考元素

### 灵异设定

- 厉鬼等级：游魂→怨灵→厉鬼→鬼王
- 符咒类型：镇魂符、驱鬼符、封印符
- 法器等级：法器→灵器→法宝→神器
- 门派：茅山、全真、龙虎山、崂山

### 恐怖场景

- 废弃医院
- 古老宅院
- 荒村野店
- 神秘古墓
- 地下密室

## 防雷指南

- 避免恐怖过度（点到为止）
- 避免解释过于详细
- 避免主角无敌
- 避免灵异设定矛盾
