# 末世生存题材配置

## 题材概述

末世生存题材以灾难后的世界为背景，讲述人类在末世环境中挣扎求生、建立秩序的故事。

## 核心要素

### 世界观设定

#### 末世类型

- 病毒爆发：丧尸横行、生物变异
- 自然灾害：洪水、地震、冰封
- 科幻灾难：AI失控、外星入侵、核战
- 灵气复苏：规则改变、旧力量觉醒

#### 社会结构

- 秩序崩溃：法律失效、道德沦丧
- 势力林立：幸存者聚居地、掠夺者、变异者
- 资源争夺：食物、水源、燃料、药品

### 人物设定

#### 主角类型

- 普通幸存者逆袭
- 军队精英
- 科研人员
- 天选之子（特殊能力）

#### 女主类型

- 同甘共苦型
- 医疗人员
- 战斗型女强人
- 神秘幸存者

### 核心冲突

- 生存危机：食物、安全、环境
- 势力对抗：聚居地争夺、派系斗争
- 人性考验：善恶抉择、牺牲与保全
- 幕后真相：灾难起源、阴谋揭露

## 写作要点

### 开篇钩子

- 灾难爆发瞬间
- 末世第一天
- 被困绝境
- 神秘幸存者出现

### 爽点设计

- 以弱胜强击败丧尸/敌人
- 建立势力、收服小弟
- 发现宝藏、资源点
- 能力觉醒/升级
- 打脸绿茶、反派

### 节奏控制

- Quest 50%：生存、探索、建设
- Fire 20%：感情羁绊
- Constellation 30%：末世真相、世界观

## 参考元素

### 末世场景

- 废墟城市
- 地下避难所
- 原始森林
- 海洋孤岛
- 极寒/酷热地带

### 能力体系

- 身体强化
- 异能觉醒
- 科技装备
- 驯兽/丧尸仆从
- 规则系能力

## 防雷指南

- 避免开篇过于绝望
- 避免主角无敌
- 避免末世设定不严谨
- 避免人性黑暗过度
