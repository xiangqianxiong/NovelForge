# 规则怪谈题材详细配置

## 核心要素

### 规则类型
- **生存规则**：必须遵守否则死亡
- **安全规则**：提供安全区域
- **隐藏规则**：需要探索发现
- **代价规则**：遵守有代价

### 世界观
- 怪谈世界：独立空间或平行世界
- 怪谈生物：无逻辑但遵守规则
- 逃生条件：满足特定条件
- 玩家身份：参与者或旁观者

## 套路模板

### 副本流
```
进入副本 → 获取初始规则 → 探索世界
发现隐藏规则 → 遵守/违反规则 → 触发后果
遇到NPC → 获得信息 → 继续探索
找到真相 → 完成逃生条件 → 逃离
```

### 升级流
```
获得规则之力 → 遵守规则获得能力
进入更危险区域 → 面对更复杂规则
揭开世界真相 → 成为规则制定者
```

## 写作要点

### 规则设计
- 规则要具体：清晰可执行
- 规则要有悖论：制造冲突
- 规则要有代价：增加紧张感

### 氛围营造
- 压抑恐怖的氛围
- 不可名状的恐惧
- 逻辑自洽的异常

### 恐怖元素
- 克苏鲁风格：不可名状
- 日式怪谈：日常中的异常
- 中式恐怖：民间传说

## 爽点设计

| 类型 | 描述 |
|------|------|
| 推理爽点 | 破解规则真相 |
| 反转爽点 | 规则被打破 |
| 逃生爽点 | 死里逃生 |
| 解谜爽点 | 揭开世界真相 |

### 反转类型
- 规则本身是陷阱
- 安全区其实最危险
- 帮助者其实是敌人
