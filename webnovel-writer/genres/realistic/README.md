# 现实题材详细配置

## 核心要素

### 现实议题
- 职场生存
- 家庭关系
- 教育问题
- 社会现象
- 人生选择

### 故事特点
- 贴近生活
- 有共鸣感
- 解决问题
- 成长蜕变

## 套路模板

### 职场逆袭
```
职场新人 → 被排挤/被打压
暗中学习 → 积累能力
抓住机遇 → 展现实力
获得认可 → 升职加薪
收获爱情 → 事业爱情双丰收
```

### 女性成长
```
普通女孩 → 遭遇困境
独立自强 → 不依附他人
专注事业 → 展现价值
遇到真爱 → 势均力敌
活出自我 → 独立女性标杆
```

## 爽点设计

| 类型 | 描述 |
|------|------|
| 逆袭爽点 | 小人物变大人物 |
| 打脸爽点 | 让看不起自己的人后悔 |
| 独立爽点 | 不靠任何人成功 |
| 爱情爽点 | 势均力敌的爱情 |

## 写作要点

### 真实性
- 细节要真实可信
- 符合社会现实
- 人物行为合理

### 共情点
- 戳中读者痛点
- 让读者有代入感
- 解决读者困惑

### 价值观
- 传递正能量
- 不狗血不浮夸
- 积极向上的主题
