# 系统流题材配置

## 题材概述

系统流是主角获得各类「系统」金手指，通过完成任务、获取奖励来不断提升实力的题材。

## 核心要素

### 系统类型

#### 任务系统

- 发布任务 → 完成奖励 → 升级强化
- 主线任务、支线任务、日常任务
- 任务难度：普通、困难、地狱

#### 兑换系统

- 积分/点数兑换
- 道具、技能、血统、属性
- 限时兑换、稀有兑换

#### 直播/网红系统

- 粉丝关注→奖励
- 直播打赏→积分
- 网红升级→解锁功能

#### 游戏系统

- 等级制度
- 技能树
- 装备强化
- 副本挑战

### 核心设定

- 系统绑定：与主角灵魂/身体绑定
- 智能助手：系统辅助AI
- 隐藏机制：隐藏任务、彩蛋
- 系统升级：系统本身可成长

## 人物设定

### 主角类型

- 屌丝逆袭型
- 豪门弃子型
- 穿越者型
- 原住民觉醒型

### 系统设定

- 全知全能型
- 单一强化型
- 混合型
- 成长型

## 写作要点

### 开篇钩子

- 系统觉醒
- 首个任务
- 新手大礼包
- 系统bug/异常

### 爽点设计

- 任务完成奖励
- 属性暴涨
- 解锁新功能
- 隐藏成就
- 打脸任务目标

### 节奏控制

- Quest 55%：任务推进
- Fire 20%：感情线
- Constellation 25%：系统奥秘

### 任务类型

- 主线任务：推动剧情
- 支线任务：获取资源
- 日常任务：稳定收益
- 隐藏任务：彩蛋奖励

## 防雷指南

- 避免系统过于万能
- 避免任务过于简单
- 避免奖励过于轻易
- 避免系统设定自相矛盾
