# 追读力学 - 钩子与爽点的设计体系

## 核心概念

### 追读力（Reader Pull）
让读者欲罢不能、想要继续读下去的力量。

## 钩子类型（Hook Types）

### 1. 悬念钩（Suspense Hook）
**原理**：留下未解之谜，引发好奇心

**模式**：
```
- "他究竟是谁？"
- "这个秘密将改变一切..."
- "三年后，一切都变了..."
```

**使用场景**：
- 章末留悬念
- 新人物出场
- 关键信息隐藏

### 2. 冲突钩（Conflict Hook）
**原理**：展示矛盾，激发读者期待

**模式**：
```
- "今天，你必须给我一个交代！"
- "这笔账，我们该算算了..."
- "既然你们找死，那就成全你们！"
```

**使用场景**：
- 即将发生战斗
- 对峙场景
- 情感冲突

### 3. 情感钩（Emotion Hook）
**原理**：情感共鸣，抓住读者心

**模式**：
```
- "她从未见过他那样的眼神..."
- "这一刻，他想起了十年前的约定"
- "有些事，比生命更重要..."
```

**使用场景**：
- 情感升温
- 生离死别
- 重逢场景

### 4. 利益钩（Benefit Hook）
**原理**：明确好处，吸引眼球

**模式**：
```
- "只要击败他，就能获得..."
- "这份机缘，错过就没了"
- "系统提示：获得稀有道具！"
```

**使用场景**：
- 获得宝物
- 任务奖励
- 升级突破

## 爽点类型（Cool Points）

### 基础爽点

| 类型 | 描述 | 触发条件 |
|------|------|----------|
| 装逼打脸 | 展示实力让小看自己的人后悔 | 被轻视 → 展现实力 → 对方震惊 |
| 反杀逆袭 | 绝境中翻盘 | 被压制 → 极限爆发 → 反败为胜 |
| 扮猪吃虎 | 隐藏实力暗中蓄势 | 示弱 → 对方大意 → 突然爆发 |
| 获得宝物 | 收获珍贵道具功法 | 探险/任务/机缘 |
| 突破境界 | 实力飞跃 | 积累 → 契机 → 突破 |
| 复仇成功 | 大仇得报 | 仇恨 → 成长 → 了结 |
| 抱得美人 | 爱情圆满 | 相识 → 相知 → 相守 |
| 兄弟情义 | 肝胆相照 | 患难 → 相助 → 共进退 |

### 爽点组合

**经典组合A：退婚流**
```
退婚羞辱 → 获得传承 → 实力打脸 → 未婚妻后悔 → 追妻火葬场
```

**经典组合B：系统流**
```
任务发布 → 完成任务 → 奖励超预期 → 实力暴涨 → 继续任务
```

**经典组合C：升级流**
```
遇到强敌 → 苦战 → 濒死突破 → 碾压反杀 → 收获资源

## 爽点密度控制

### 章节爽点分布
- 每章至少 **1个小型爽点**
- 每3-5章 **1个中型爽点**
- 每10-15章 **1个大型爽点（高潮）**

### 节奏红线
- Quest（主线）连续不超过 5 章
- Fire（感情）断档不超过 10 章
- Constellation（世界观）断档不超过 15 章

## 债务理论

### 什么是追读债务
每次埋下钩子，就欠读者一个答案。
欠债太多，读者会失去耐心。

### 债务管理
- 小钩子 → 1-3章内兑现
- 中钩子 → 5-10章内兑现
- 大钩子 → 贯穿整卷

### 最佳实践
- 埋设新钩子前，先兑现旧钩子
- 同时最多维持 3-5 个大钩子
- 每章至少解决一个小悬念

## Hook 设计公式

### 强 Hook = 冲突 + 未知 + 利益

```
强钩子 = 明确的冲突 + 未知的答案 + 读者的利益期待
```

### 章末 Hook 公式
```
本章完成 + 留一个悬念 + 引发期待
```

### 示例
"他成功击败了对手，正要庆祝时，却发现这只是更大阴谋的开始..."

## 情绪节奏

### 黄金比例
```
压抑（2-3章） → 爆发（1章） → 余韵（1-2章）
```

### 情绪山峰
```
      *
    *   *
  *       *
*           *
1  2  3  4  5
```

### 避免情绪疲劳
- 不要连续高能
- 紧张后要缓和
- 给读者喘息空间
