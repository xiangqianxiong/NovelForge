# 物理法则追踪 - 网文世界观规则约束

## 核心原则

**设定即物理**：网文世界的规则必须像物理定律一样被遵守。打破规则需要代价，超越规则需要解释。

## 法则分类

### 1. 境界法则（Realm Laws）

定义境界之间的差距和限制。

```
| 法则 | 说明 | 常见漏洞 |
|------|------|----------|
| 境界压制 | 高境界对低境界有天然压制 | 低境界突然打赢高境界无解释 |
| 感知限制 | 低境界无法感知高境界行为 | 无感知的角色突然"看到"高境界动作 |
| 行动限制 | 低境界无法干涉高境界 | 炼气期影响筑基期战斗 |
| 寿元限制 | 境界对应寿命上限 | 低境界活过应有寿命 |
```

### 2. 能量法则（Energy Laws）

定义灵力、真气、法力等能量的流转规则。

```
| 法则 | 说明 | 检查点 |
|------|------|--------|
| 能量守恒 | 消耗必须来自某处 | 灵力/法力消耗来源 |
| 恢复速率 | 恢复需要时间 | 连续战斗灵力来源 |
| 转化效率 | 能量转化有损耗 | 灵石换灵力的比例 |
| 存储上限 | 容器有容量限制 | 储物袋、丹田容量 |
```

### 3. 空间法则（Space Laws）

定义空间移动和存储的规则。

```
| 法则 | 说明 | 检查点 |
|------|------|--------|
| 传送限制 | 传送有距离/境界限制 | 传送阵覆盖范围 |
| 储物限制 | 物品存取有条件 | 储物袋活人/死人 |
| 领域法则 | 领域内规则特殊 | 进入他人领域的代价 |
| 空间切割 | 独立空间时间流速 | 秘境内外时间差 |
```

### 4. 时间法则（Time Laws）

定义时间相关的规则。

```
| 法则 | 说明 | 检查点 |
|------|------|--------|
| 修炼耗时 | 突破需要时间积累 | 一夜连续突破多境界 |
| 时间流逝 | 不同空间时间不同 | 秘境时间换算 |
| 记忆时效 | 记忆保留有期限 | 跨越太久还记得细节 |
| 因果顺序 | 先因后果 | 预知未来但不改变过去 |
```

### 5. 因果法则（Causality Laws）

定义因果关系的约束。

```
| 法则 | 说明 | 检查点 |
|------|------|--------|
| 代价原则 | 获得必有代价 | 无代价获得逆天能力 |
| 信息传递 | 信息传播需要媒介 | 千里之外即时知道 |
| 蝴蝶效应 | 小事可引发大事 | 大事毫无铺垫 |
| 合理动机 | 行动需要理由 | 反派无理由针对主角 |
```

## 法则违规检测清单

### 境界违规（Realm Violations）

```
检查本章是否存在：
□ 低境界角色做出高境界专属行为
□ 境界压制被无视
□ 感知范围超出当前境界
□ 越级战斗无合理解释（秘术/底牌/机缘）
□ 寿元异常
```

### 能量违规（Energy Violations）

```
检查本章是否存在：
□ 灵力消耗无来源
□ 恢复速率不合理
□ 连续高强度战斗无恢复
□ 储物空间突然变大/变小
□ 能量转化无损耗
```

### 空间违规（Space Violations）

```
检查本章是否存在：
□ 传送超出设定范围
□ 违反储物袋使用规则
□ 领域使用无代价
□ 空间跳跃无铺垫
```

### 时间违规（Time Violations）

```
检查本章是否存在：
□ 突破耗时与设定不符
□ 秘境时间换算错误
□ 角色记得不可能记得的细节
□ 时间线矛盾（前后时间不一致）
```

### 因果违规（Causality Violations）

```
检查本章是否存在：
□ 无代价获得重要资源
□ 信息传递违反物理限制
□ 事件缺乏前置铺垫
□ 角色行为缺乏动机
```

```json
{
  "physics_rules": {
    "realm_system": {
      "enabled": true,
      "压制规则": "境界差一级=压制，差两级=秒杀",
      "感知规则": "感知范围=境界等级×10米"
    },
    "energy_system": {
      "enabled": true,
      "恢复规则": "休息一夜恢复30%，丹药加速",
      "存储上限": "丹田容量=境界等级×100单位"

    "space_system": {
      "enabled": false,

    },
    "time_system": {

      "修炼耗时": "突破一小境=1-3月，大境=1-3年"

      {
        "rule_id": "fire_attribution",
        "description": "火系功法必须配火系灵根",

    ]
  }

```

## 违规报告格式

```json
{
  "violations": [
    {
      "rule_id": "realm压制",
      "severity": "critical",
      "location": "第3段",
      "description": "炼气三层角色击败筑基一层",
      "evidence": "原文：主角炼气三层，轻松击败筑基期修士",
      "violation_type": "境界压制被无视",
      "fix_hint": "需要解释：主角使用了克制性秘术/对方重伤/对方压制境界"
    }
  ]
}
```

## 常见漏洞模式

| 漏洞类型 | 示例 | 修复方式 |
|----------|------|----------|
| 越级挑战无解释 | 炼气打赢筑基 | 补充：对方重伤/使用秘术/特殊宝物 |
| 连续突破无代价 | 一夜三突破 | 补充：特殊机缘/燃寿/根基不稳 |
| 灵力来源不明 | 无限使用大招 | 补充：丹药/吸收他人灵力/秘术副作用 |
| 储物袋超限 | 装入活人/太多物品 | 补充：特殊储物法宝/暂时寄存 |
| 感知超限 | 低境界看穿高境界 | 补充：特殊瞳术/宝物辅助 |
| 时间倒流 | 回到过去改变 | 补充：时间法则限制/代价极大 |
