# `/webnovel-init` - 初始化小说项目

## 功能说明

初始化一个新的网文项目，创建完整的项目结构和模板文件。

## 引导信息

创建新小说时，引导用户填写以下信息：

### 必填项
- **书名**：小说的名称
- **题材**：从以下题材中选择（最多组合2个）
  - 玄幻修仙、都市异能、末世、系统流、高武、西幻、无限流
  - 古言、宫斗宅斗、青春甜宠、豪门总裁、职场婚恋、种田
  - 悬疑灵异、规则怪谈、克苏鲁、知乎短篇

### 选填项
- **主角姓名**：默认"主角"
- **目标字数**：默认 200万字
- **目标章节数**：默认 600章
- **金手指名称/类型/风格**
- **核心卖点**
- **主角结构**：单主角/多主角
- **女主配置**：无女主/单女主/多女主
- **反派层级**

## 初始化产出

```
{书名}/
├── .webnovel/
│   ├── state.json（运行时状态）
│   ├── backups/
│   ├── archive/
│   └── summaries/
├── 设定集/
│   ├── 世界观.md
│   ├── 力量体系.md
│   ├── 主角卡.md
│   ├── 女主卡.md（可选）
│   ├── 主角组.md（可选）
│   └── 反派设计.md
├── 大纲/
│   └── 总纲.md
├── 正文/
└── 审查报告/
```

## state.json 结构

```json
{
  "project_info": {
    "title": "",
    "genre": "",
    "created_at": "",
    "target_words": 2000000,
    "target_chapters": 600
  },
  "progress": {
    "current_chapter": 0,
    "total_words": 0,
    "current_volume": 1
  },
  "protagonist_state": {
    "name": "",
    "power": {"realm": "", "layer": 1}
  },
  "strand_tracker": {
    "last_quest_chapter": 0,
    "last_fire_chapter": 0,
    "last_constellation_chapter": 0
  }
}
```

## 执行示例

用户输入：`/webnovel-init`，书名《逆天改命》，题材玄幻修仙，主角林逸

系统应该：
1. 创建项目目录结构
2. 生成 state.json
3. 生成所有设定模板
4. 生成大纲模板
5. 显示创建成功的文件和目录

## 题材组合

用 `+` 连接两个题材（主辅比例建议 7:3）：
- 玄幻+系统流
- 都市异能+规则怪谈
- 古言+宫斗宅斗
