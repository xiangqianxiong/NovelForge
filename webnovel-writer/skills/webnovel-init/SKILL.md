# `/webnovel-init` - 初始化小说项目

## 功能说明

初始化一个新的网文项目，**以小说名称为目录名**创建项目文件夹，在该目录中进行所有后续创作（写作、审查、查询等）。

## 流程说明

### 第一步：检查是否已有项目目录

在执行任何操作前，先检查工作目录中是否已存在与书名匹配的项目目录：
- 如果已存在同名项目目录 → 直接进入该目录并告知用户"项目已存在，可以直接开始写作"
- 如果不存在 → 继续第二步创建新项目

### 第二步：引导信息

创建新小说时，引导用户填写以下信息：

### 必填项
- **书名**：小说的名称（将作为项目目录名，如《逆天改命》→ 目录名 `逆天改命`）
- **题材**：从以下题材中选择（最多组合2个）
  - 玄幻修仙、都市异能、末世、系统流、高武、西幻、无限流
  - 古言、宫斗宅斗、青春甜宠、豪门总裁、职场婚恋、种田
  - 悬疑灵异、规则怪谈、克苏鲁、知乎短篇

### 选填项
- **主角姓名**：默认"主角"
- **目标字数**：默认 200万字
- **目标章节数**：默认 600章
- **金手指名称/类型/风格**
- **核心卖点**
- **主角结构**：单主角/多主角
- **女主配置**：无女主/单女主/多女主
- **反派层级**
- **参考风格**：选择写作风格参考（可多选）
  - 古龙：诗意武侠，短句留白，充满哲理
  - 金庸：史诗武侠，细腻描写，文化底蕴深厚
  - 鲁迅：冷峻犀利，深刻批判，揭露人性

### 第三步：用户确认创建

在创建目录和文件之前，**必须等待用户确认以下信息后再执行**：
- 确认书名（即项目目录名）
- 确认题材选择
- 确认主要设定信息

**不确认不创建。**

### 第四步：创建项目目录

用户确认后，以书名为目录名创建完整的项目结构：

## 初始化产出（目录名 = 书名）

```
{书名}/                ← 项目根目录，目录名 = 小说书名
├── .webnovel/
│   ├── state.json（运行时状态，记录书名、题材、进度等）
│   ├── backups/
│   ├── archive/
│   └── summaries/
├── 设定集/
│   ├── 世界观.md
│   ├── 力量体系.md
│   ├── 主角卡.md
│   ├── 女主卡.md（可选）
│   ├── 主角组.md（可选）
│   └── 反派设计.md
├── 大纲/
│   └── 总纲.md
├── 正文/
└── 审查报告/
```

## 后续操作提示

项目创建成功后，告知用户：
- 项目目录位置：`{书名}/`
- 下一步命令：`/webnovel-plan 1` 规划第一卷大纲，或 `/webnovel-write 1` 开始写作
- 所有后续创作都在该项目目录内进行

## 执行示例

用户输入：`/webnovel-init`，书名《逆天改命》，题材玄幻修仙，主角林逸

系统应该：
1. 创建项目目录结构
2. 生成 state.json
3. 生成所有设定模板
4. 生成大纲模板
5. 显示创建成功的文件和目录

## 题材组合

用 `+` 连接两个题材（主辅比例建议 7:3）：
- 玄幻+系统流
- 都市异能+规则怪谈
- 古言+宫斗宅斗
