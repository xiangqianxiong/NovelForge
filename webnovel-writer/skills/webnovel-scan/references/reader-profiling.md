# 读者画像分析

## 核心读者群体

### 起点中文网

**主流读者特征**：

| 维度 | 特征 |
|------|------|
| 年龄段 | 18-35岁为主 |
| 性别 | 男频85%+ |
| 职业 | 学生、职场新人 |
| 阅读场景 | 通勤、睡前、午休 |
| 单次阅读 | 30-60分钟 |

**内容偏好**：
- 爽点类型：打脸、碾压、装逼、打斗
- 节奏要求：快节奏，不喜欢拖沓
- 世界观：接受度高，越详细越好
- 更新期待：日更或隔日更

**付费特征**：
- 月票打赏意愿强
- 订阅付费习惯良好
- 对优质内容愿意付费

### 番茄小说

**主流读者特征**：

| 维度 | 特征 |
|------|------|
| 年龄段 | 25-45岁为主 |
| 性别 | 男性略多，下沉市场 |
| 职业 | 蓝领、服务业 |
| 阅读场景 | 碎片时间、通勤 |
| 单次阅读 | 15-30分钟 |

**内容偏好**：
- 爽点类型：简单直接，越爽越好
- 节奏要求：节奏紧凑
- 世界观：不要太复杂
- 更新期待：日更优先

**付费特征**：
- 免费阅读为主
- 对广告接受度高
- 付费意愿相对较低

### 晋江文学城

**主流读者特征**：

| 维度 | 特征 |
|------|------|
| 年龄段 | 16-30岁为主 |
| 性别 | 女性95%+ |
| 职业 | 学生、白领 |
| 阅读场景 | 睡前、通勤 |
| 单次阅读 | 1-2小时 |

**内容偏好**：
- 爽点类型：甜、宠、虐（甜虐交织）
- 节奏要求：中等节奏，感情线细腻
- 世界观：可以复杂，但感情第一
- 更新期待：日更或隔日更

**付费特征**：
- 积分订阅为主
- 霸王票打赏意愿强
- 对完结文偏好高

### 七猫小说

**主流读者特征**：

| 维度 | 特征 |
|------|------|
| 年龄段 | 30-50岁为主 |
| 性别 | 女性略多 |
| 职业 | 下沉市场用户 |
| 阅读场景 | 碎片时间 |
| 单次阅读 | 15-30分钟 |

**内容偏好**：
- 爽点类型：打脸、逆袭、甜宠
- 节奏要求：快节奏
- 世界观：简单直接
- 更新期待：日更

**付费特征**：
- 免费阅读为主
- 付费用户以会员为主

## 题材读者画像

### 玄幻修仙类

**典型读者**：
- 男频主力军
- 18-30岁
- 对升级、打斗有强烈偏好
- 喜欢「变强」的核心驱动

**阅读期待**：
- 清晰的升级体系
- 持续的战斗爽点
- 世界观扩展
- 金手指合理化

### 都市异能类

**典型读者**：
- 男频主力
- 20-35岁
- 代入感要求高
- 喜欢「现实+超能」组合

**阅读期待**：
- 专业领域的碾压展示
- 都市生活的异能应用
- 商业/职场暗线
- 感情线辅助

### 言情类（女频）

**典型读者**：
- 女频绝对主力
- 16-28岁
- 感情投入度高
- 喜欢「磕CP」

**阅读期待**：
- 男主/女主人设亮眼
- 感情互动甜/虐交织
- 男二/女二助攻或对立
- 身份揭秘/反转

### 悬疑灵异类

**典型读者**：
- 男女均衡
- 20-35岁
- 智力挑战需求
- 喜欢解谜过程

**阅读期待**：
- 悬念持续
- 线索合理埋设
- 结局反转或揭秘
- 恐怖氛围营造

### 无限流/副本类

**典型读者**：
- 男频偏多
- 18-30岁
- 游戏玩家转化
- 喜欢智斗和生存

**阅读期待**：
- 副本设计精彩
- 任务目标明确
- 道具/能力获取
- 死亡威胁持续

## 读者画像提取方法

### 从书评/数据中提取

1. **书评分析**：从书评中提取读者反馈关键词
2. **数据趋势**：从追读率、完读率分析读者行为
3. **题材偏好**：从同类型爆款反推读者喜好

### 画像描述模板

```
## 读者画像：{题材}

### 人口统计
- 年龄：{主要区间}
- 性别：{男/女/混合}
- 地域：{主要地区}
- 职业：{主要职业}

### 行为特征
- 阅读时段：{高峰时段}
- 单次时长：{平均时长}
- 更新期待：{日更/隔日更}
- 完读率：{该题材平均完读率}

### 内容偏好
- 爽点类型：{具体类型}
- 节奏要求：{快/中/慢}
- 感情线：{需求程度}
- 世界观：{接受度}

### 付费特征
- 付费意愿：{高/中/低}
- 付费方式：{订阅/打赏/全订}
- ARPPU：{该题材平均消费}
```
