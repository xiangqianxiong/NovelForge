# `/webnovel-plan` - 规划大纲

## 功能说明

根据题材特点和已有设定，生成卷级规划和章节大纲。

## 参数

- `[卷号]`：要规划的卷号，如 `1`、`2-3`

## Strand 节奏系统

规划时必须遵循 Strand 节奏系统：

| Strand | 含义 | 理想占比 |
|--------|------|----------|
| Quest | 主线剧情 | 60% |
| Fire | 感情线 | 20% |
| Constellation | 世界观扩展 | 20% |

**节奏红线**：
- Quest 连续不超过 5 章
- Fire 断档不超过 10 章
- Constellation 断档不超过 15 章

## 大纲结构

### 卷级大纲
```
### 第{卷号}卷
- 核心冲突：
- 关键爽点：
- 卷末高潮：
- 主要登场角色：
- 关键伏笔（埋/收）：
```

### 章级大纲
```
## 第{章号}章 {标题}
- 主线目标：
- 阻力：
- 爽点设计：
- 伏笔关联：
- 章末钩子：
```

## 执行流程

1. 读取 `设定集/` 下的所有设定文件
2. 读取 `大纲/总纲.md`
3. 根据题材特点生成卷级规划
4. 生成详细的章级大纲
5. 遵循节奏红线分配 Strand
6. 写入 `大纲/第{卷号}卷.md`

## 输出示例

```
# 第1卷 废物崛起

## 核心冲突
林逸因经脉堵塞无法修炼，被未婚妻退婚，遭受屈辱。

## 章节规划

| 章号 | 标题 | Strand | 主线目标 |
|------|------|--------|----------|
| 1-3 | 废物退婚 | Quest | 开篇屈辱，获得传承 |
| 4-6 | 初次修炼 | Quest | 展现金手指威力 |
| 7-10 | 打脸嘲讽者 | Quest/Fire | 小高潮，赢得尊重 |

## 爽点分布
- 第3章：金手指觉醒
- 第6章：首次战胜嘲讽者
- 第10章：未婚妻后悔
```
